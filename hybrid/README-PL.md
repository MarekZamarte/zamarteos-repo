# ZamarteOS Hybrid FP4

Ten katalog dotyczy wyłącznie wariantu Hybrid dla Fairphone 4.

- Docelowa baza sprzętowa: istniejący port UBports FP4 / Halium 11.
- Docelowy userspace: ZamarteOS/Linux, nie Ubuntu Touch.
- Android/Halium: ukryta warstwa zgodności sprzętowej, bez androidowego launchera i aplikacji.
- Stan: etap audytu źródeł; brak gotowego obrazu.

Zobacz [plan architektury](../docs/HYBRID-PLAN-PL.md).

Nie instaluj artefaktów z workflow audytu. Nie są obrazami systemu.
