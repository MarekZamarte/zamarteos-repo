# ZamarteOS Weather for Sailfish OS

Samodzielna aplikacja pogodowa dla Sailfish OS 5 / ARM64.

- wyszukiwanie miejscowości po nazwie
- bieżąca temperatura, odczuwalna temperatura i wiatr
- prognoza dzienna na 7 dni
- polskie opisy warunków pogodowych
- dane z Open-Meteo, bez konta i klucza API

Aplikacja nie zastępuje ekranu głównego Sailfish OS i nie zmienia telefonii, modemu ani dźwięku rozmów.
